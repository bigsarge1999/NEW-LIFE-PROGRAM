Import a calendar file

Export your Google or Outlook calendar as an .ics file, then upload it here. Every event gets added to this shared board.

Google Calendar: Settings → select calendar → "Export" (downloads a .zip with .ics files inside).

Outlook: Calendar → right-click calendar → "Save calendar" or use Share → "Get a link" then download.
